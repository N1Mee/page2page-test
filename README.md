# page2page-test

Тестовый репозиторий для режима «сайт в своём репозитории» (page2page).

- `index.html` — страница, которую правит бот.
- `ci-mode.txt` — `ok` или `fail`. `fail` роняет сборку намеренно: так проверяется
  автоматический откат правки по красной сборке.
- GitHub Pages отдаёт `index.html` из ветки `main`.

Инструкция целиком — в README основного репозитория, раздел
«Сайт в своём репозитории клиента».
